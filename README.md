# ANDROID-Matrix-Display-AI

An  APK that displays a Matric screebn created with Claude.ai

Prompts:
<HR/>
Create an Android APK  that displays a series of hexadecimal numbers,<BR>
each line having 4 sets of 4 characters separated by a space, that scrolls green text in a monospaced font.<BR>
Text is green on a black background.<BR>
scroll speed should be 1 page per 5 seconds<BR><BR>
OUTPUT was HexScroll.APK

<HR/>
Using the same character size and scroll speed, create an APK to display a "Matrix movie" style screen<BR><BR>
OUTPUT was MatrixRain.APK
<HR/>
Using character half the size and same  scroll speed, create an APK to display a "Matrix rain" call this "Matrix Rain 2"<BR><BR>
OUTPUT was MatricRain2.APK
<HR/>
Create an APK to display a full-screen "Radar" display in blue<BR><BR>
OUTPUT was Radar.APK
